# Choose Methodology (guia rápido)

Guia curto para escolher metodologia sem complicação.

## Regra prática

- Se tiver dúvida, comece com **STRIDE**.
- Se o contexto for específico, escolha a metodologia especializada.

## Quando usar cada uma

- **STRIDE** (**Mature**)  
  Use para web/API/cloud e baseline técnico geral.

- **LINDDUN** (**Evolving**)  
  Use para privacidade, PII, LGPD/GDPR e consentimento.

- **NIST Data-Centric** (**Evolving**)  
  Use quando o foco principal é proteção de dados críticos/classificados.

- **OCTAVE Allegro** (**Evolving**)  
  Use para visão orientada a ativos e risco organizacional.

- **CIA/CIA-DIE** (**Evolving**)  
  Use para workshops rápidos, comunicação executiva e onboarding.

- **PASTA** (**Specialized**)  
  Use para análise avançada orientada a ataque, impacto e risco de negócio.

- **PLOT4ai** (**Specialized**)  
  Use para sistemas AI/LLM, RAG, agentes, prompts, embeddings e pipelines.

## Como escolher em 30 segundos

1. Tema principal é segurança técnica geral? -> **STRIDE**  
2. Tema principal é privacidade/dados pessoais? -> **LINDDUN**  
3. Tema principal é dado crítico/classificado? -> **NIST Data-Centric**  
4. Tema principal é risco de negócio por ativos? -> **OCTAVE Allegro**  
5. Tema principal é análise avançada de ataque/impacto? -> **PASTA**  
6. Tema principal é IA/LLM/agentes? -> **PLOT4ai**

> A recomendação automática continua no backend e pode ser usada como ponto de partida.
