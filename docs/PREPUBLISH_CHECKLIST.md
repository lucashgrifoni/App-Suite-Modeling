# Checklist final pré-publish (rápido)

Use este checklist no dia da publicação.

- [ ] CI verde (python + web + smoke)
- [ ] Smoke suite ok (`tests/test_smoke_release_candidate.py`)
- [ ] E2E smoke mínimo UI ok (`npm run e2e:smoke`)
- [ ] Build web validado (padrão ou portátil)
- [ ] Docs centrais atualizadas
- [ ] `CHANGELOG.md` atualizado
- [ ] Release notes RC2 prontas
- [ ] Limitações conhecidas documentadas
- [ ] Tag/version pronta conforme convenção
- [ ] Artefatos de release revisados
