# Histórico resumido — evolução da UI (web)

Substitui trilhos documentais paralelos (*modernization* → *refinement phase 2* → *phase 3 polish* → *phase 4 features* → *final release assets*), cada um com plano/validação/handoff. Esses ficheiros foram **removidos na higiene round 2** por duplicarem conhecimento já incorporado no código e na documentação viva.

## Linha do tempo (alto nível)

1. **Modernização** — diagnóstico UX/base, tokens e fluxos principais.
2. **Refinement fase 2** — refinamento pós-modernização (critérios fechados).
3. **Fase 3 — product polish** — consistência de produto e cópia.
4. **Fase 4 — features** — diagrama, histórico, PDF, extensões de jornada.
5. **Final release assets** — checklist de assets e validação pré-release.

Estado consolidado: entregas consideradas **integradas**; manutenção contínua em [`UI.md`](UI.md), [`DESIGN_SYSTEM_FOUNDATION.md`](DESIGN_SYSTEM_FOUNDATION.md) e no código em `apps/web/`.
